# Promotion plan: from the test copy to the live accounts

Written 2026-10-29. Nothing here has been promoted: the live folder is still on `prod` with no changes. Every step below needs the owner's go-ahead first.

## How it is shipped

All the new code ships in one release with **every new part off** (the switches in [SWITCHES.md](SWITCHES.md)); the parts are then turned on **one at a time** by one line in `.env` and a loop restart. Turning a part off again is deleting that line and restarting the loop: no code change, no git. The data folders (books, candles, decisions) are never touched by a release.

One exception needs a decision: the test copy's accounts default to **no open-risk cap** (as decided), while the live accounts have the 50% cap today. So the release comes with `AGENTIC_RISK_CAP_GEMMA_SHORT=50` and `AGENTIC_RISK_CAP_QWEN_SHORT=50` written into the live `.env`, which keeps today's behaviour, and the cap is turned off later by changing that line to `off`.

## The order of switching on

Each step: turn on, watch, and only then go to the next. Rollback = remove the line and restart that loop.

| # | Step | Switch | What to watch | Restart |
|---|---|---|---|---|
| 0 | Release the code with everything off (and the risk cap pinned at 50) | `AGENTIC_RISK_CAP_*=50` | the loops run as before; dashboard shows the scorecard and the open-risk line | dashboard; each loop between rounds |
| 1 | Install the watchdog task (optional) | none (a Windows scheduled task, `scripts/install_watchdog_task.ps1`) | a killed loop comes back within 10 minutes | none |
| 2 | Gemma calls every 2 hours, with the short-term prompt, hourly tables and its own recent calls | `AGENTIC_CALL_EVERY_GEMMA_SHORT=120` | each round finishes inside the interval (the dashboard's pace line); no stalls; the scorecard fills in | Gemma loop, between rounds |
| 3 | Qwen calls every hour | `AGENTIC_CALL_EVERY_QWEN_SHORT=60` | no 429 or quota errors; a round (about 45 minutes) fits the interval | Qwen loop |
| 4 | Mild calls at 75% size | `AGENTIC_PLAN_<ACCOUNT>=mild` | lots on Overweight/Underweight trades are smaller | the account's loop |
| 5 | Hold off on conditional calls | add `wait` | the "not opened: the agent said to wait" lines match what the agents wrote | the account's loop |
| 6 | The agent's own stop | add `levels` | trades marked "agent stop"; their stops are 0.5 to 3 times ours | the account's loop |
| 7 | Several trades per pair | `AGENTIC_MAX_PER_PAIR_<ACCOUNT>=2` (then 3) | open risk on the dashboard stays where you want it | the account's loop |
| 8 | Hedging | `AGENTIC_HEDGE_<ACCOUNT>=on` | a call against an open trade opens a second trade beside it | the account's loop |
| 9 | No risk cap | `AGENTIC_RISK_CAP_<ACCOUNT>=off` | the open-risk line shows the share at risk; the account can be wiped out | the account's loop |
| 10 | Slippage on fills | `AGENTIC_SLIPPAGE_<ACCOUNT>=on` | results a little worse than before, stops most of all | the account's loop |
| 11 | Phone-monitor pages | (artifact update) | the pages show the open-risk line, trade counts and the call schedule | none |

Steps 2 and 3 should be done one account at a time: Gemma first, one full day of the scorecard, then Qwen.
